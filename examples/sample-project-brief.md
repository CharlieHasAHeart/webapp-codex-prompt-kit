# Sample Project Brief

Build a lightweight issue tracker for small software teams.

## Users

- indie hackers
- small engineering teams
- solo developers

## MVP

- create project
- create issue
- list issues
- update issue status
- assign issue
- comment on issue
- basic dashboard
- email notification for assignment

## Preferred Stack

- Next.js
- TypeScript
- PostgreSQL
- Prisma
- Auth.js
- pnpm
- Playwright

## Constraints

- no enterprise SSO
- no billing in MVP
- no mobile app
- no complex workflow automation
