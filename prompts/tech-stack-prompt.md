# Prompt: Generate `tech-stack.md`

Generate `tech-stack.md`.

## Responsibility

`tech-stack.md` defines selected technologies and forbidden alternatives.

## Include

- Purpose
- Source of Truth
- Codex Usage
- Non-Goals
- Technology summary table
- Runtime versions
- Package managers
- Frontend stack
- Backend stack
- Database and ORM
- Auth approach
- Validation libraries
- Testing stack
- Deployment target
- Forbidden alternatives
- Short rationale for major choices

## Rules

- Keep this document short and firm.
- Prefer `Use X` and `Do not use Y`.
- Do not include commands; commands belong in `dev-environment.md`.
- Reference `project-decisions.md` for shared decisions.
- Keep within the tech stack length budget.

Output complete Markdown suitable for `docs/tech-stack.md`.
