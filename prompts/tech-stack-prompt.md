# Tech Stack Prompt

```markdown
Please generate `tech-stack.md` for this project.

Responsibility:
`tech-stack.md` tells Codex which technologies are selected and which alternatives are forbidden.

Required sections:

1. Purpose
2. Source of Truth
3. Codex Usage
4. Non-Goals
5. Technology Summary
6. Language and Runtime
7. Package Manager
8. Frontend Framework
9. Backend Framework
10. Database
11. ORM or Query Builder
12. Authentication
13. Validation
14. State Management
15. Styling Approach
16. Testing Stack
17. Code Quality Tools
18. Deployment Target
19. Third-Party Services
20. Forbidden Technologies
21. Rationale
22. Assumptions
23. Open Questions

Rules:
- Make all technology choices explicit.
- If Node.js is used, choose exactly one of npm, pnpm, yarn, or bun.
- If Python is used, choose exactly one execution/dependency approach, such as uv, poetry, pipenv, or raw python/pip.
- Do not include installation commands, runtime commands, database fields, API request/response bodies, implementation tasks, or Codex behavior rules.

Output complete Markdown that can be saved directly as `tech-stack.md`.
```
