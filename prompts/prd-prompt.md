# PRD Prompt

```markdown
Please generate `prd.md` for this project.

Responsibility:
`prd.md` tells Codex what product to build.

Required sections:

1. Purpose
2. Source of Truth
3. Codex Usage
4. Non-Goals
5. Product Background
6. Target Users
7. User Problems
8. Product Goals
9. MVP Scope
10. Out of Scope
11. Requirements
12. User Stories
13. Core Workflows
14. Business Constraints
15. Success Criteria
16. Assumptions
17. Open Questions

Rules:
- Use requirement IDs such as `REQ-001`.
- Write requirements as explicit product decisions.
- Separate MVP requirements from future ideas.
- Do not include database schema, API contracts, technology choices, runtime commands, file paths, or Codex behavior rules.
- Avoid vague language. If uncertainty exists, put it in `Assumptions` or `Open Questions`.

Output complete Markdown that can be saved directly as `prd.md`.
```
